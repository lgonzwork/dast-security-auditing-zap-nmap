# DAST SECURITY AUDITING & VULNERABILITY SCANNING (OWASP ZAP & Nmap)

## Overview
This portfolio suite models an active Dynamic Application Security Testing (DAST) architecture, combining network reconnaissance via Nmap with automated CI/CD web and API vulnerability assessments via OWASP ZAP within GitHub Actions to identify, triage, and document application-level attack surfaces.

## Projects Overview
- **Project 1: Network Reconnaissance & Port Scanning (Nmap CLI)**  
  *Focus:* Performing host discovery, port scanning, service version detection, and OS fingerprinting to audit network exposure prior to web application testing.
- **Project 2: Automated DAST in CI/CD Pipeline (GitHub Actions & OWASP ZAP)**  
  *Focus:* Integrating OWASP ZAP into a GitHub Actions pipeline to execute automated spidering, active scanning, and vulnerability detection (SQLi, XSS, Headers) upon repository deployment events.
